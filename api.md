# Обзор API Ibronevik.ru Taxi

Данный документ содержит краткую справку по API, включая описание эндпоинтов, их назначение и группировку по категориям.

Базовый URL для всех эндпоинтов: `https://ibronevik.ru/taxi/api/v1/`

## 1. Авторизация и Управление Пользователями

### Регистрация и Авторизация

- **POST /register/**
  - **Назначение:** Регистрация нового пользователя (Клиента, Водителя, Агента, Администратора). Поддерживается регистрация по телефону или email.
- **POST /auth/**
  - **Назначение:** Авторизация пользователя по логину (телефон, email, WhatsApp, Telegram) и паролю/коду. Поддерживает различные методы аутентификации (пароль, четырехзначный код).
- **GET /logout/**
  - **Назначение:** Деавторизация текущего пользователя.
- **GET /token/**
  - **Назначение:** Получение токена и проверочного хеша для авторизованного пользователя.
- **GET /token/authorized**
  - **Назначение:** Получение токена и проверочного хеша для авторизованного пользователя (аналогично `/token/`).
- **POST /remind/**
  - **Назначение:** Восстановление пароля пользователя по email, телефону, Telegram или WhatsApp.
- **POST /newpass/**
  - **Назначение:** Изменение пароля авторизованного пользователя.

### Информация о Пользователях

- **GET /user/{u_id1,u_id5}**
  - **Назначение:** Получение информации о пользователях с указанными ID.
- **GET /user/authorized**
  - **Назначение:** Получение информации об авторизованном пользователе.
- **GET /user/**
  - **Назначение:** Для администратора - информация обо всех пользователях; для остальных - об авторизованном пользователе.
- **GET /user/authorized/favorite**
  - **Назначение:** Информация об избранных пользователях для авторизованного пользователя.
- **GET /user/{u_id}/favorite**
  - **Назначение:** Информация об избранных пользователях для указанного пользователя.
- **GET /user/authorized/referral**
  - **Назначение:** Информация о рефералах авторизованного пользователя.
- **GET /user/{u_id}/referral**
  - **Назначение:** Информация о рефералах указанного пользователя.
- **GET /user/authorized/inner**
  - **Назначение:** Информация о внутренних клиентах авторизованного пользователя.
- **GET /user/{u_id}/inner**
  - **Назначение:** Информация о внутренних клиентах указанного пользователя.

### Редактирование Пользователей

- **POST /user/{u_id}**
  - **Назначение:** Редактирование данных указанного пользователя. Доступно администраторам и самим пользователям для редактирования своих данных.
- **POST /user/**
  - **Назначение:** Редактирование данных авторизованного пользователя.
- **GET /user/{u_id}/favorite/{f_u_id1,f_u_id5}/add**
  - **Назначение:** Добавление пользователей в избранные для указанного пользователя.
- **GET /user/authorized/favorite/{f_u_id1,f_u_id5}/add**
  - **Назначение:** Добавление пользователей в избранные для авторизованного пользователя.
- **GET /user/{u_id}/favorite/{f_u_id1,f_u_id5}/remove**
  - **Назначение:** Удаление пользователей из избранных для указанного пользователя.
- **GET /user/authorized/favorite/{f_u_id1,f_u_id5}/remove**
  - **Назначение:** Удаление пользователей из избранных для авторизованного пользователя.
- **GET /user/{u_id1,u_id5}/referral/link**
  - **Назначение:** Информация о реферальных ссылках для указанных пользователей.
- **GET /user/authorized/referral/link**
  - **Назначение:** Информация о реферальных ссылках для авторизованного пользователя.
- **GET /referral/code/{ref_code}/check**
  - **Назначение:** Проверка реферального кода на доступность.
- **GET /email/verification/start**
  - **Назначение:** Отправка письма с ссылкой для верификации email.
- **GET /email/verification/complete&ev_hash={...}**
  - **Назначение:** Верификация email пользователя на основании контрольной суммы.

## 2. Управление Машинами

### Информация о Машинах

- **GET /user/{u_id1,u_id5}/car/{c_id4,c_id8}**
  - **Назначение:** Информация о конкретных машинах, принадлежащих указанным пользователям.
- **GET /user/{u_id1,u_id5}/car/**
  - **Назначение:** Информация обо всех машинах, принадлежащих указанным пользователям.
- **GET /user/authorized/car**
  - **Назначение:** Информация о машинах авторизованного пользователя.
- **GET /user/authorized/car/driven**
  - **Назначение:** Информация о машине, которой управляет авторизованный пользователь.
- **GET /car/{c_id4,c_id8}**
  - **Назначение:** Информация о конкретных машинах по ID.
- **GET /car/**
  - **Назначение:** Информация обо всех машинах.

### Редактирование Машин

- **POST /car/**
  - **Назначение:** Создание новой машины для авторизованного пользователя.
- **POST /user/{u_id}/car/**
  - **Назначение:** Создание машины для указанного пользователя (доступно администратору или водителю для себя).
- **POST /car/{c_id}**
  - **Назначение:** Редактирование данных машины по ID.
- **POST /user/{u_id1,u_id5}/car/{c_id}**
  - **Назначение:** Редактирование и переназначение машины указанному пользователю (только администратору).
- **POST /car/{c_id}/drive/**
  - **Назначение:** Выбор машины для управления текущим водителем.

## 3. Управление Поездками (Заказами Такси)

### Создание и Получение Поездок

- **POST /drive**
  - **Назначение:** Создание новой поездки/заказа.
- **GET /drive**
  - **Назначение:** Получение данных об активных поездках текущего пользователя.
- **GET /drive/now**
  - **Назначение:** Получение данных о поездках, ожидающих одобрения (доступно водителям и администраторам).
- **GET /drive/archive**
  - **Назначение:** Получение данных об архивных поездках текущего пользователя.
- **GET /drive/get/{b_id1,b_id5}**
  - **Назначение:** Получение детальной информации об указанных поездках.

### Управление Поездками

- **POST /drive/get/{b_id}**
  - **Назначение:** Управление поездкой с указанным ID. Различные действия:
    - `set_confirm_state`: Подтверждение поездки.
    - `set_offer`: Предложение поездки водителю.
    - `set_waiting_time`: Изменение максимального времени ожидания.
    - `set_performer`: Утверждение водителя исполнителем или попытка водителя стать исполнителем.
    - `set_arrive_state`: Изменение статуса "машина на месте".
    - `set_start_state`: Начало поездки.
    - `set_complete_state`: Завершение поездки.
    - `set_cancel_state`: Отмена поездки.
    - `set_rate`: Оценка поездки.
    - `set_tips`: Указание чаевых.
    - `edit`: Редактирование деталей поездки.
- **POST /location**
  - **Назначение:** Запись текущих координат авторизованного пользователя в базу данных.

## 4. Управление Рейсами (Для продажи билетов, Stadium Profile)

### Создание и Получение Рейсов

- **POST /trip**
  - **Назначение:** Создание нового рейса.
- **GET /trip**
  - **Назначение:** Получение данных об активных рейсах (для клиентов, водителей, админов).
- **GET /trip/now**
  - **Назначение:** Получение данных о рейсах, ожидающих клиентов (доступно клиентам).
- **GET /trip/get/{t_id1,t_id5}**
  - **Назначение:** Получение детальной информации об указанных рейсах.

### Управление Рейсами

- **POST /trip/get/{t_id}**
  - **Назначение:** Управление рейсом с указанным ID. Действие `edit`:
    - `edit`: Редактирование деталей рейса.

## 5. Управление Билетами (Stadium Profile)

### Загрузка и Получение Билетов

- **POST /trip/get/{t_id}/ticket/write/**
  - **Назначение:** Загрузка и удаление билетов на сайт для указанного рейса.
- **GET /trip/get/{t_id}/ticket/read/**
  - **Назначение:** Получение списка загруженных билетов или конкретного билета для указанного рейса.
- **GET /trip/get/{t_id}/ticket/read/?seat={seat}&pdf={pdf}**
  - **Назначение:** Получение билета в виде файла (PDF, если запрошено).
- **POST /trip/get/{t_id}/ticket/send/buyer/email**
  - **Назначение:** Отправка сообщения покупателю билета.
- **POST /trip/get/{t_id}/ticket/edit/**
  - **Назначение:** Редактирование информации о билете (место, цена, статус, код QR и т.д.).

### Сводные Данные по Билетам

- **GET /schedule/ticket**
  - **Назначение:** Получение списка рейсов с доступными билетами по расписанию.
- **GET /schedule/ticket/select**
  - **Назначение:** Получение сводных данных по билетам (купленные, забронированные, доступные) для определенного расписания.
- **GET /ticket/check/**
  - **Назначение:** Проверка билета по его коду (для администраторов и билетеров).
- **GET /ticket/check/log**
  - **Назначение:** Вывод логов проходов билетов.

## 6. Корзина и Предзаказы (Stadium Profile)

### Обычная Корзина

- **GET /cart**
  - **Назначение:** Просмотр содержимого корзины текущего пользователя.
- **GET /cart?prod={t_id}&prop={seat}[&count=1]**
  - **Назначение:** Управление элементами в корзине (добавление, удаление).
- **GET /cart/clear**
  - **Назначение:** Очистка корзины пользователя.
- **GET /cart/move**
  - **Назначение:** Передача элементов корзины другому пользователю.

### Корзина для Оповещений/Предзаказа

- **GET /cart_block**
  - **Назначение:** Просмотр корзины с отслеживаемыми или предзаказываемыми местами.
- **GET /cart_block?prod={t_id}&prop={seat}[&count={count}][&notice={0|1}]**
  - **Назначение:** Управление корзиной для оповещения и предзаказа (добавление, удаление, изменение количества, настройка уведомлений).
- **GET /cart_block/clear**
  - **Назначение:** Очистка корзины для оповещения и предзаказа.
- **POST /cart_block/status**
  - **Назначение:** Редактирование статусов элементов в корзине оповещений.
